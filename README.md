# Sanal Ağ Laboratuvarı
Bu proje, VirtualBox üzerinde Debian tabanlı 5 farklı makineden oluşan, güvenli ve yönetilebilir bir Sanal Kurumsal Ağ Laboratuvarı simülasyonudur. Sistem; yönlendirme (routing), ağ servisleri, veri depolama ve uç kullanıcı yönetimi gibi temel ağ konseptlerini uygulamalı olarak test etmek amacıyla tasarlanmıştır.
